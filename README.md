## What it does

Drag and drop DWG files — the program **finds every drawing frame automatically**, makes a PDF for each one, and can send them straight to the printer.

- Works with **single-sheet and multi-sheet** DWG files
- **Detects paper size and orientation** (A3 / A4)
- **One merged PDF** or **one PDF per frame**
- **Print instantly** — choose printer, copies, color
- **Batch** convert many files at once
- Warns when a drawing uses fonts that aren't installed
- Works with **AutoCAD and CADian** (see *Tested CAD versions* below)
